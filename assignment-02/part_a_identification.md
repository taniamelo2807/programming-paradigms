Part A - Identification

Snippet 1

Concept or pattern: Encapsulation with property

Label: OOP

This snippet shows encapsulation using a property. The class stores the real value in a private attribute and controls access to it through the title property.

Snippet 2

Concept or pattern: Composition

Label: OOP

This snippet shows composition because the Library class contains and manages playlists. A library has playlists, instead of being a playlist.

Snippet 3

Concept or pattern: Strategy

Label: Pattern

This snippet shows the Strategy pattern because the sorting behavior is delegated to another object. This makes it possible to change the sorting method without changing the playlist class.

Snippet 4

Concept or pattern: Observer

Label: Pattern

This snippet shows the Observer pattern because an event is published to all subscribed callbacks. When the event happens, every subscriber is notified automatically.
