# Expense Tracker Project

## Introduction

This project is a Personal Expense Tracker developed in Python.  
The objective of the project is to analyze a list of expenses and generate useful information from the dataset.

The program works with expense records that contain:

- date
- category
- amount
- description

Using this data, the program can calculate totals, averages, category statistics, and identify the highest and lowest expenses.

The assignment was divided into multiple parts to compare different programming paradigms.  
The same problem was solved using imperative, procedural, and functional programming approaches.

This helped demonstrate how each programming style solves problems in different ways.
